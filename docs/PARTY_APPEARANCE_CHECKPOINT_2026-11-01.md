## Architecture and ownership

- Versioned, bounded appearance JSON is party data. Curated design, layout, accent, font and artwork enums are validated by the backend and normalized defensively in the browser. Existing host-only commit/revision/retry guarantees remain the authority.
- UI agent owns isolated appearance model, controls, renderer and CSS. Integration lead owns editor/API/media-draft integration, affected tests, review, source and release. Backend agent owns additive schema/storage access package and independent staging/privacy/preservation checks.
- Personal images are prepared locally as metadata-free JPEGs up to 1600px and 1.5 MB. Source JPEG/PNG/WebP up to 20 MB / 48 megapixels; unsupported formats receive an actionable message. Binary drafts use IndexedDB so photo selection survives email authentication and refresh without inflating localStorage. No new upload service.
- Storage access is being designed against existing Supabase resources. Uploads must be bound to a verified host and the intended party; guests may see the invitation image without acquiring host edit powers or enumerating the image collection. Concrete permission/schema changes require approval review before persistence, with reversible prior-contract retention.
